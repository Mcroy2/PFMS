PFMS Alpha 0.2.2 Demo Edition

Created by Michael Croy II & Atlas • 2026 PFMS

This is a local, working Alpha application. Extract the complete ZIP and double-click index.html. Data persists in the browser on that device. Use Backup and Restore to protect or move the complete database.

Upgrade

  1. Export a JSON backup from your current PFMS build.
  2. Keep the old folder and backup as rollback copies.
  3. Extract Alpha 0.2.2 into a new folder and open index.html.
  4. Restore the JSON backup. PFMS migrates Alpha 0.1.8, 0.2.0, and 0.2.1 data automatically.

Demo Mode

Open Settings → Demo Data and select Load Demo Data. Demo Mode replaces the active database after confirmation, so export a backup first. All demo transactions, splits, budgets, vendors, workflows, and reports are real editable records.
